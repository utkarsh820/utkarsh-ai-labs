    🎓 Module: Git & GitHub Mastery Resources (0 → Elite)¶

    Course: Version Control Fundamentals
    Topic: Curated Free & Open-Source Resources
    Cost: $0 (All Free)

    📘 How to Use This Learning Path¶

    The Strategy: 1. Start: Pick one resource from "Beginner" and complete it fully. 2. Practice: Apply what you learn immediately to a real project. 3. Progress: Move to "Intermediate" only after you're comfortable with daily commands. 4. Master: Use "Elite" resources to contribute to open source and understand internals.

    🟢 Level 1: Beginner (0 → 1)¶

    Goal: Understand what Git is, make your first commit, and push to GitHub.

    Resource Type Time Why It's Great Link
    GitHub Skills Interactive Lab 1-2 hrs Official GitHub courses. You learn by completing tasks in real repositories. skills.github.com
    Learn Git Branching Visual Game 1 hr The best visual tool to understand branches, merges, and rebasing interactively. learngitbranching.js.org
    Git Immersion Guided Tour 2 hrs Step-by-step lab exercises that build muscle memory for basic commands. gitimmersion.com
    Codecademy: Git (Free) Interactive Course 2 hrs Hands-on browser-based learning with instant feedback. codecademy.com/learn/learn-git

    ✅ Milestone: You can create a repo, add files, commit, and push to GitHub.

    🟡 Level 2: Intermediate (1 → 10)¶

    Goal: Master branching, merging, resolving conflicts, and professional workflows.

    Resource Type Time Why It's Great Link
    Pro Git Book Book (Free PDF) 5-8 hrs The official Git bible. Read Chapters 1-3 thoroughly. Written by Git creators. git-scm.com/book
    Oh My Git! Open-Source Game 2-3 hrs A real-time strategy game that visualizes Git internals and operations. ohmygit.org
    Atlassian Git Tutorials Articles 3 hrs Industry-standard explanations of workflows (Gitflow, feature branches). atlassian.com/git
    Git - The Simple Guide Cheat Sheet 30 min No-nonsense reference for daily commands. Perfect for your desk. rogerdudler.github.io/git-guide
    Visualizing Git Visual Tool 1 hr See exactly what happens to your commit graph with each command. git-school.github.io/visualizing-git

    ✅ Milestone: You can resolve merge conflicts, use branches for features, and write good commit messages.

    🟣 Level 3: Advanced (10 → 50)¶

    Goal: Understand Git internals, advanced commands, and team collaboration.

    Resource Type Time Why It's Great Link
    Pro Git Ch. 9-10 Book Chapter 3 hrs Deep dive into Git plumbing, internals, and how data is stored. git-scm.com/book
    Git Branching - Advanced Interactive 2 hrs Master rebase, cherry-pick, reset, and reflog. learngitbranching.js.org
    GitHub Actions Docs Documentation 3 hrs Learn CI/CD: automate testing and deployment on every push. docs.github.com/actions
    Git Hooks Tutorial 2 hrs Automate workflows (linting, testing) before commits/pushes. githooks.com
    Conventional Commits Specification 1 hr Industry standard for writing structured, automated commit messages. conventionalcommits.org

    ✅ Milestone: You can rebase safely, use git reflog to recover from mistakes, and set up GitHub Actions.

    🔴 Level 4: Elite (50 → 100)¶

    Goal: Contribute to open source, maintain projects, and understand Git at the source-code level.

    Resource Type Time Why It's Great Link
    First Contributions Guided Repo 2 hrs A safe sandbox repository designed specifically for your first Pull Request. github.com/firstcontributions
    Git Source Code Source Code Ongoing Read the actual C code that powers Git. Understand the engine. github.com/git/git
    Git Rev News Newsletter Monthly Deep technical insights into Git development and internals. git.github.io/rev_news
    Up For Grabs Project List Ongoing Find beginner-friendly issues in real open-source projects to fix. upforgrabs.net
    Git LFS Docs Documentation 2 hrs Learn to handle large files (models, datasets) in Git repositories. git-lfs.com
    Semantic Versioning Specification 1 hr Learn how to version your projects professionally (v1.0.0, v2.1.3). semver.org

    ✅ Milestone: You have merged a Pull Request in an open-source project and understand Git's object database.

    🏆 Academy Challenges: Earn Your Badges¶

    Complete these projects to prove your skills:

    🥉 Bronze Badge: "First Commit"¶

    • Complete GitHub Skills: Introduction to GitHub
    • Create a public repo with a README
    • Make 3 commits with descriptive messages
    • Push to GitHub

    🥈 Silver Badge: "Branch Master"¶

    • Complete Learn Git Branching (main levels)
    • Create a feature branch in your repo
    • Make changes, commit, and merge via Pull Request
    • Resolve a merge conflict intentionally

    🥇 Gold Badge: "Open Source Contributor"¶

    • Complete First Contributions
    • Find a repo with "good first issue" label
    • Submit a Pull Request that gets merged
    • Add GitHub Actions to auto-test your code

    💎 Elite Badge: "Git Wizard"¶

    • Write a custom Git hook (pre-commit or pre-push)
    • Use git rebase -i to squash 3+ commits
    • Recover a "lost" commit using git reflog
    • Contribute to a major open-source project (1k+ stars)

    💡 Pro Tips for Success¶

    1. Use Git Daily: Even for small projects. Muscle memory is key.
    2. Read Error Messages: Git errors are actually helpful. Read them carefully.
    3. Break Things: Create a test repo and try dangerous commands (reset --hard, rebase) to see what happens.
    4. Help Others: Answer Git questions on Stack Overflow. Teaching solidifies learning.
    5. Stay Curious: When you use a command, ask "What is Git actually doing here?"

    "The expert has failed more times than the beginner has even tried."
