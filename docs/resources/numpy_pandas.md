## 💡 Pro Tips for Success

1.  **Never Use Loops:** If you're using `for row in df.iterrows()`, you are doing it wrong. Find the vectorized equivalent.
2.  **Chain Methods:** Pandas is designed for method chaining (e.g., `df.query().groupby().mean()`). It keeps code readable.
3.  **Mind the Data Types:** Using `Category` schemas and narrower integers (e.g., `int32` instead of `int64`) can save you 50%+ of your RAM.
