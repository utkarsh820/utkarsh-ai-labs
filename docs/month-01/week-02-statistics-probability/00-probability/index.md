# Probability

Welcome to the Probability module of the Academy. In this section, we build the foundational language for dealing with uncertainty and randomness. Probability is the very bedrock upon which all statistical modeling, machine learning algorithms, and data science methodologies rest.

## Curriculum Structure

This module is designed following our 5-level format (Intuition, Definition, Formula, Examples, and Case Study) to ensure a deep, practical understanding:

1. [Introduction to Probability](./01-Introduction-to-Probability.md)
   - Grasp the basic intuition and formulas behind theoretical and empirical probability.

2. [Conditional Probability and Bayes' Theorem](./02-Conditional-Probability-and-Bayes.md)
   - Learn how to update your beliefs based on new evidence—the core concept behind many AI decision-making engines.

3. [Random Variables](./03-Random-Variables.md)
   - Understand how we map messy real-world events into clean mathematical numbers, calculating Expected Value and Variance along the way.

By the end of this module, you'll be able to quantify risk and use code to simulate real-world probabilistic scenarios.
